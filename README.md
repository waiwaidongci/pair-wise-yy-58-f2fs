# pair-wise-yy-58 大型构件吊装三维校核平台

围绕大型转换桁架吊装方案，提供三维场景、时间轴校核、冲突定位、条件评论和多角色签署工作流。新增**离线批次变更**能力：现场工程师在断网平板上修改步骤参数、提交会签意见，系统按批次记录每项改动的基线版本、修改人和字段值，联网后与当前锁定版本、会签意见逐字段三方合并。

## 离线批次合并机制

- **离线记录**：断网时所有步骤字段与意见改动进入离线批次（`src/offline/types.ts`）。每条字段改动记录基线值、修改人、现场值；同一字段反复修改只更新现场值，基线值锁定在首改瞬间。
- **三方合并**：联网提交时由模拟服务端（`src/offline/server.ts`）逐字段比对「批次基线 / 平板现场 / 服务端当前锁定版本」：
  - 服务端未动 → 干净入库；双方同改 → 列为字段冲突，界面展示三个值供人工选择保留哪一方。
  - 字段被会签锁定或方案已锁定发布 → 拒绝覆盖，改动标记 blocked，服务端值不动。
  - 旧基线批次按服务端留存的版本历史（revisionHistory）重建比对基准，未触碰字段不产生伪冲突。
- **风险失效**：合并落地后重算净空（<1.5m）与荷载率（>90%），出现基线版本没有的新风险时，原会签结论失效，相关步骤上的会签意见（含已关闭意见）自动重新打开并标注原因，就绪度、冲突清单同步刷新。
- **失败重试**：同步失败保留未完成批次，6 秒倒计时自动重试；服务端按变更 id 幂等入库，已成功字段与意见不会重复写入，`finalize` 同样幂等。
- **版本一致**：合并完成后步骤、冲突、会签就绪度与 Apollo 方案快照整体对齐到同一新版本（同步中心实时显示本地 / 服务端 / 快照三者版本）。
- **草稿找回**：批次与本地草稿分别持久化在 localStorage；刷新或重启后自动找回未完成批次，历史批次可一键「找回待同步内容」生成新批次继续编辑。

## 页面

- 三维复核 / 模型与参数：检查器表单编辑后显式「保存到同步批次」，字段旁显示基线值与会签锁定标记。
- 冲突与评论：规则冲突、条件意见（断网可提交）、合并后重新打开的意见带失效原因。
- 多角色会签：四角色签署状态、发布门禁；会签失效时顶部红色横幅提示。
- **离线同步**（新增）：连接状态、批次明细（基线/现场值、成功/冲突/锁定状态）、冲突人工裁决、风险失效结果、自动重试倒计时、历史草稿找回，以及内置「断网会签演练台」。

## 演练路径

离线同步页底部演练台：① 断网改 S-03 参数 → ② 模拟同事并改同字段、会签锁定字段、四角色先完成会签、注入同步失败、服务端锁定发布 → ③ 联网观察字段冲突选择、锁定拒绝、新风险导致会签失效与意见重开、失败重试不重复入库。

## 技术栈

Vue 3、Quasar、Pinia、Vue Router、Apollo Client、GraphQL、Three.js、Vite、TypeScript。

## 运行

```bash
npm install
npm run dev          # 端口 62058
npm run build        # 类型检查 + 构建
npm run test:merge   # 合并引擎端到端验证（34 项断言）
```

数据草稿与离线批次保存在浏览器 `localStorage`，Apollo 内存缓存保存吊装方案版本快照；`src/offline/server.ts` 为可注入故障与会签事件的模拟服务端。
